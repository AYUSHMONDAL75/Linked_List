# Linked List Repository

This repository contains C implementations of various linked list data structures and their applications.

---

## Programs Included

### 1. Circular Linked List
* **Description:** Implementation of circular linked list operations in C.
* **Main File:** `Circular_Linked_List.c`

### 2. Double Linked List
* **Description:** Implementation of doubly linked list operations in C.
* **Main File:** `Double_Linked_List.c`

### 3. Singular Linked List
* **Description:** Implementation of singly linked list operations in C.
* **Main File:** `Singular_Linked_List.c`

### 4. Stack Using Singular Linked List
* **Description:** Implementation of a stack data structure using a singly linked list in C, supporting push, pop, and display operations.
* **Main File:** `Stack_using_Singular_Linked_List.c`
